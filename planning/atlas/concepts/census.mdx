## The problem

Sefer's project sidebar lists every book's chapters and verses on open. Parsing and plating 66 books to get that pays mostly for plating, not for reading.

## The solution

Galley already keeps each book's [[toc]] in the [[pantry]] ([[invariants]] 4). `tocAll` packs those rows for every book into one [[ticket]]-generated buffer and reads no text. A "TOC only" flag on `parse` was rejected because it still pays the plating path.

## Trade-offs

- Labels and verse lists only, no token pointers: those belong to products galley does not keep.
- `\c 12b` arrives as chapter 0 with label `12b`; check the label.
- A reference that dropped its text still lists, but cannot answer UTF-16 questions, and says so (`keepText`).

## Show me

How Sefer builds its sidebar, then how odd chapters and verses come through, then the buffer's layout. From `galley/src/toc.md`:

```js
for (const id of project) galley.update(id, await read(id));   // once, at open
const census = Census.open(galley.tocAll());                   // once, for the sidebar
for (const book of census) sidebar.add(book.code, book.chapters, book.verseCount);   // GEN 50 1533
```

```text
\c 12b         chapter  number 0 (malformed as a NUMBER), label "12b"
\v 1,3,5 …     verse    first 1, last 5, label "1,3,5", members [1] [3] [5]

header      magic "TOCS", version, flags, bookCount, the three strides, directoryAt
directory   per book: code, chaptersAt, chapterRows, versesAt, verseRows, idAt, idLen, membersAt, memberRows
rows        per book: chapter rows, verse anchors, then members, each block 4-aligned
ids         every id's UTF-8, in directory order
```

## How it works

- **A warm parse is mostly its plate.** Per book on MRK (83 KB), a `parse` with every chunk a cache hit is 311 µs; the same work without the wire plate is 45 µs; the census row set is already resident in the [[pantry]]'s pinned [[toc]]. `encode` takes `&Pantry`, not `&mut`, because nothing here can run the cache.
- **No token indices.** The [[dish]]'s rows carry token and designator indices; tokens are the rebuildable tier and not resident, so the census carries label spans and member runs instead.
- **Lazy reader.** A sidebar over 66 books touches 66 directory entries and no verse row.

## Composes with

Reads the [[toc]] the [[pantry]] pins per book. Declared against [[ticket]] ([[wire]]). Served by `toc`/`tocAll` on the [[galley-package]] handle; read by [[sefer]] through `toc-reader.ts`.
