## The problem

About 35 hand-kept book tables across the org's repos disagree, even on Matthew's number. Every book picker, citation box, file name and stitcher spells its own. And a text's verses only mean something against a numbering tradition, which nothing in the workspace knew.

## The solution

One crate of data with no runtime parsing. `canon-gen` writes Rust consts and their TypeScript twins from `canon/data/`, so Sefer gets plain TS with no wasm `init()`, and both languages pass the same `canon/fixtures/*.json`. canon depends on [[mise]] alone. Its Rust consumers are galley, [[bento]] (book entries, names and `sort`) and [[bttwriter]] (titles and file names). The numbering half is [[versification]].

## Trade-offs

- Data, not code, is the review surface: `books.tsv`, the scheme JSON, the sniffing rules and each gateway language's `names/<locale>.tsv` are what a person checks. The generated tables are checked only for freshness.
- No Unicode library, so the generator writes what `fold` makes of each character (NFKD, accents dropped, marks ordered) into a table. A Unicode bump on either side could move a rare character.
- Book names are each translation's own `\toc` lines: 32 gateway languages, reviewed once. fa, pmy and zh have no Primary text and fall back to English.

## Show me

```rust
canon::book(MAT)                         // usfm_number "41", canonical_index 40
canon::parse_book("1samuel")             // Some(1SA)
canon::parse_book_in("Éxodo", &["es"])   // Some(EXO): es is es-419, accents fold
canon::name(MAT, &["fr"], Form::Long)    // "Matthieu", locale "fr"
canon::usfm_file_name(MAT)               // "41-MAT.usfm"
```

```ts
import fr from "@wycliffeassociates/scripture-kitchen/canon/names/fr";
name("MAT", "long", [fr]);   // { text: "Matthieu", locale: "fr", form: "long" }
parseBook("matthieu", [fr]); // "MAT"
```

## How it works

- **Two numbers, never one.** `canonical_index` is the place among the 66 (Matthew 40); `usfm_number` is the file number (Matthew 41).
- **A code wins.** `parse_book` tries a code in any case before any name, so "Jon" is Jonah, even in Tok Pisin, whose John is "Jon". Sefer decides it the same way.
- **Names fall back, and say so.** Each locale asked for, then en_ulb's names, then the book table's English. `Named` reports which locale and form answered.
- **One TS module per locale**, so a bundle carries only the languages it imports (`NAME_LOCALES` lists them for a dynamic import).
- **Refreshing names** is `gen/fetch-gateways.sh` (BIEL API, clones), `harvest-names` (onion's lexer over `\toc1-3`), a review, then `cargo run -p canon-gen`.
