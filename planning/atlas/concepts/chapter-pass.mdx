## The problem

A Sous verdict depends on every book, an edit touches one chapter, and a host republishes findings after edits. Rereading 66 books per publish is the cost to avoid.

## The solution

The chapter is the unit of rework ([[invariants]] 5). **Map** observes one chapter as a pure function of its own text, so its result caches by content. **Fold** stitches a book's chapters in order and owns any seam state. **Judge** reads every book's aggregate and decides; **locate** rescans current text for sites. Config reaches only judge, so moving a threshold never rereads text.

## Trade-offs

- Map cannot look across a chapter break; seam behaviour is fold arithmetic.
- Nothing carries across a book boundary.
- Retained observations cost memory; the word rule (~5 KB a chapter) opts out.

## Show me

Two books, from `sous-chef/core/src/pass.md`: chapters map alone, a book folds, the whole project judges.

```rust
// book MRK, projected text, chapters starting at 0, 16 and 41
let obs: Vec<_> = mrk.chapters().map(|c| pass.map(c)).collect(); // each alone: caches by content
let mrk_agg = pass.fold(&rows(&obs));      // ChapterObs rows, book order → Aggregate in book coordinates
let gen_agg = pass.fold(&rows(&gen_obs));  // no state crosses a book
pass.judge(&[&mrk_agg, &gen_agg], &config, &mut out); // only judge sees config
out.finish();                              // Findings
```

## How it works

[[code:sous-chef/core/src/pass/chapter.rs#ChapterPass]] is the trait; [[code:sous-chef/core/src/lib.rs#Brigade]] is the three passes run together. Charter invariants 2–4:

- **Book is the discourse unit.** There is no `Carry` on the trait.
- **Chapter is the rebuild unit.** `map` reads only its chapter's projected text, verse rows and key, so chapters run in any order, on any thread, or not at all on a cache hit.
- **Raw observations are config-free.** Only `judge` sees a `Config`, so a host re-judges without remapping.
- **Judgment is corpus-level.** Whether a comma attached to a letter is a slip depends on every other book.
- **`locate` only places.** It reads text to site what the counts decided, never to decide.

`RETAIN_CHAPTERS` is each rule's answer to "may a host keep my observation?" `Words` says no: ~5 KB a chapter against the substrate's 0.3, 4–5 MB per Bible to save ~200 µs (`expediter.md`).
