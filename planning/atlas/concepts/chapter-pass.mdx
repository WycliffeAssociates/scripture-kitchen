## Why

Charter invariants 2–4:

- **Book is the discourse unit.** No state crosses a book; there is no `Carry` on the trait.
- **Chapter is the rebuild unit.** `map` reads only its chapter's projected text, verse rows and key, so chapters run in any order, on any thread, or not at all when a cache holds the answer.
- **Raw observations are config-free.** Only `judge` sees a `Config`, which is what lets a host re-judge without remapping.
- **Judgment is corpus-level.** Whether a comma attached to a letter is a slip depends on every other book.
- **`locate` only places.** It reads text to site what the counts decided, never to decide.

`RETAIN_CHAPTERS` is each rule's answer to "may a host keep my observation?" `Words` says no: ~5 KB a chapter against the substrate's 0.3, 4–5 MB per Bible to save ~200 µs (`expediter.md`).
