## The problem

Sous Chef reads a whole translation and flags things that look inconsistent, such as a name spelled one way 40 times and another way twice. Whether something is odd depends on every other book, yet a translator edits one chapter at a time. If each keystroke in Mark re-read all 66 books, checks would be far too slow to run while typing. So how do we split a check so most of its work can be kept?

## The solution

Every rule is written as four steps. **Map** counts one chapter on its own. **Fold** adds up a book's chapter counts, in order. **Judge** looks at all books' totals and decides what is odd. **Locate** finds where in the text each decision points. Only map reads chapter text, and it needs nothing from other chapters, so an unchanged chapter's counts can be reused. The obvious alternative, one function per rule that reads the whole project, is simpler but must redo everything on every edit. Settings (thresholds, what to ignore) only reach the judge step, so changing a setting never re-reads text.

## Trade-offs

- A rule cannot look across a chapter break while counting; anything that spans chapters must be done as arithmetic in the fold.
- Nothing may carry from one book to the next. A rule that needs "what the previous book did" cannot be written.
- Keeping chapter counts costs memory. The word rule's counts are about 5 KB a chapter, so it opts out of being kept.

## How it works

`ChapterPass` is the trait; `Brigade` is the three passes run together. Charter invariants 2–4:

- **Book is the discourse unit.** There is no `Carry` on the trait.
- **Chapter is the rebuild unit.** `map` reads only its chapter's projected text, verse rows and key, so chapters run in any order, on any thread, or not at all on a cache hit.
- **Raw observations are config-free.** Only `judge` sees a `Config`, so a host re-judges without remapping.
- **Judgment is corpus-level.** Whether a comma attached to a letter is a slip depends on every other book.
- **`locate` only places.** It reads text to site what the counts decided, never to decide.

`RETAIN_CHAPTERS` is each rule's answer to "may a host keep my observation?" `Words` says no: ~5 KB a chapter against the substrate's 0.3, 4–5 MB per Bible to save ~200 µs (`expediter.md`).
