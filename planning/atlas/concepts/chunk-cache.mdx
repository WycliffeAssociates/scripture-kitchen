## The problem

Sefer resends the whole book per keystroke, and typing in Mark 4 leaves 15 chapters byte-identical. Reparsing them is waste, but wasm memory never shrinks and a stale hit is worse than a miss.

## The solution

Each [[chunk]]'s tokens, CST and local lint are keyed by a hash of its bytes plus the custom-marker set and the two book-level facts it depends on ([[invariants]] 4, 5). A changed chapter just misses, so there is no invalidation to get wrong, and assembly from cached chunks is byte-identical to a cold parse. A byte ceiling with LRU eviction bounds it.

## Trade-offs

- Every lookup hashes the chapter, hit or not: the per-keystroke floor is one pre-scan (~1 ms per 5 MB) and one checksum per chapter.
- Books of two chunks or fewer skip it; a cached parse measured 1.02–1.14x a fresh one there.
- It is the one store the budget evicts.

What one entry holds, and the counters a host can read, from `galley/src/pantry/chunks.rs` and `pantry.md`:

```text
chunks.parse(text, opts)  ->  the same bytes onion::wire::parse would plate,
                              with every unchanged chunk served from memory

key   = (xxh3-128 of the chunk's bytes, custom-marker list fingerprint, chunk 0's carry-outs)
value = Products { cst, tokens (chunk-relative), local LintReport, Carried, bytes }

pantry.chunk_stats() -> ChunkStats { misses, hits, evictions, len, resident_bytes }
```

## How it works

- **Content, not position.** Reordering chapters, undoing an edit or reopening a book all hit.
- **The key names everything the value depends on.** The bytes lex differently under two [[extensions]] lists, and chunk 0's `\usfm` version and is-scripture bit gate local lint rules. Omitting either would be a correctness bug, not a performance one (`pantry.md`, "This is the law").
- **Byte-identical output.** The assembled dish equals a cold [[plate]] (`galley/tests/chunks.rs`, [[code:galley/tests/chunks.rs#the_folded_dish_is_byte_identical_to_a_cold_one]]), and lint equals a fresh walk cold, warm, edited, fused, evicted and undone.
- **Small books bypass** (`UNCACHED_CHUNKS = 2`). On en_ulb's five two-chunk books, fifty keystrokes in Jude would otherwise leave 52 entries and 74 KB.
- **A ceiling makes it safe.** A wasm high-water mark is permanent. A hand-rolled LRU evicts by last-touched tick; at dozens to hundreds of entries a linear scan is enough.
- **Dirty seams are remembered** as `OpenBoundary`, so repeat calls widen to the fused unit without re-lexing.
