## Show me

```text
Edit { from, to, insert }        replace source[from..to] with insert

overlay(target, source) → 6 edits, ascending, non-overlapping
  insert "\p\n"   at the target's \v 21
  insert "\n\q1" "\n\q2" "\n\q1" "\n\q2"   after verse 23's text   ← one edit, shared position
```

(The overlay example is from `galley/src/overlay.md`.)

## Why

`edit.rs`: one shape of "here is a change", three speakers in onion (lint fixes, the formatter, the diff port) and one in galley ([[overlay]]). An editor applies all of them the same way, as byte splices through its UTF-16 shim. `check_edits` validates a set before it is applied; `apply` and `apply_splices` are the reference appliers.

Inserts at one position cross as one edit so an applier that splices last-first still lands them in order.
