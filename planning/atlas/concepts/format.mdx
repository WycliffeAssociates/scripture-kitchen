## The problem

Teams want a consistent layout (paragraph and heading markers on their own lines), sometimes for one chapter, with no change to text and without making the load path lossy.

## The solution

Format is the one opt-in writer of new bytes ([[invariants]] 1, 3). It returns [[edit]]s from lint's formatting fixes plus layout-only rules, applied as one transaction, and it deletes Pad. A chapter-scoped format is the whole-book list filtered engine-side to the window, dropping any edit that straddles it.

## Trade-offs

- A scoped format still lints the whole book.
- A straddling edit is dropped whole, so a seam may stay untidy.
- Layout is a fixed set of switches (`verse_breaks`, `char_marker_breaks`, per-rule flags); a house style outside them needs its own edits.

## Show me

`playground --format-trace`, default options, on the scratch book in [[cst]]: 3 edits over 125 bytes. Watch the verses join their paragraph's line and the surplus spaces before `spoke.` go. Before:

```usfm
\p
\v 1 Jesus wept.\f + \ft why\f* Then
\v 2-3 he \nd Lord\nd*   spoke.
\s1 A heading
\q1 \v 4 Bread.
```

After:

```usfm
\p \v 1 Jesus wept.\f + \ft why\f* Then \v 2-3 he \nd Lord\nd* spoke.
\s1 A heading
\q1 \v 4 Bread.
```

`verse_breaks: Remove` joins verses onto their paragraph's line; `VerseBreaks::Keep` would keep them.

## How it works

- **Two passes, no duplicated rules.** Format runs [[lint]], keeps the fixes of rows flagged `formatter` plus any named `repairs`, then a second walk evaluates the Form-channel rows (`Severity::Form`, which lint never reaches). The two sets merge and collide by row order: first writer wins, the loser is not emitted.
- **The [[mask]]'s no-normalization law does not bind it.** It invents whitespace and engine `FixStr`s, never prose.
- **Scope engine-side, never in JS.** [[code:onion/src/format.rs#format_edits_in]] filters the whole-book transaction to a window. An edit straddling the edge is dropped whole; a multi-edit claim (`bridge-empty-verses`) is kept only if all of it is inside (`onion-wasm/README.md`).

## Composes with

Reads [[lint]] and the Form channel over the same rows. Emits [[edit]]s. Crosses as `onion-wasm`'s `Edits` handle with UTF-16 spans ([[onion-wasm]]).
