## The problem

An editor calls the engine on every keystroke, across a whole project of books. Re-reading every book each time is too slow, so something has to remember earlier work. The proofreader also needs the engine's view of the text, but the two products are kept independent. Someone has to hold the memory and do the translating between them.

## The solution

Galley is that someone. It is the only crate allowed to depend on both the USFM engine ([[onion]]) and the proofreader ([[sous-core]]). Neither engine depends on galley or on each other. All state lives here, in one cache (the [[pantry]]), so the engines stay simple text-in, answers-out functions. Galley also builds the one JavaScript package apps install.

## Trade-offs

- Every cross-product feature must go through galley, so it is the busiest crate.
- One cache layer means one place to reason about memory, but it also has to account for every byte it keeps.
- Building it for JavaScript pulls the whole engine in through [[onion-wasm]].

## Show me

The modules, one job each:

```text
galley::pantry      the one caching layer (chunks, books, derived stores, budget)
galley::sous        OnionBook, Expediter, publish_onion_findings, settings
galley::find        literal search over a projection
galley::overlay     match formatting
galley::toc / mask  the census and mask-map wires
galley::corpus      the ONCP envelope
galley::wasm        the Galley handle (feature "wasm")
```

## How it works

- **The only place the engines meet.** "Anything that might be considered stateful lives here and NEVER in the engines" (`galley/src/lib.rs`). `galley::sous` owns the Onion→Sous seam entire.
- **One caching layer.** Everything kept between calls is in the [[pantry]] or a store it defines (`architecture.md`).
- **The JS superset.** galley's cdylib links onion-wasm's shims, so one module exports `Galley` and every onion door. A test pins the exact export list because a cdylib silently drops what nothing references.
- **Depends on** [[onion]], [[sous-core]], [[mise]], [[ticket]]; [[onion-wasm]], `wasm-bindgen` and serde only under `wasm`; `rayon` only under `parallel`.

## Composes with

Implements the [[pantry]], [[chunk-cache]], [[expediter]], [[onion-book]], [[find]], [[overlay]] and the [[census]], [[mask-map]], [[find-buffer]] and [[corpus]] wires. Ships as the [[galley-package]].
