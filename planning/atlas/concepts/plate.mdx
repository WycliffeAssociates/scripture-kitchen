## The problem

A keystroke wants tokens, tree, diagnostics and the chapter/verse index together, and crossing a typical book costs about 80 µs, so separate calls multiply it. Prebuilt views cost more than they save: building and converting them was three fifths of the call.

## The solution

Parse once and write the raw products into one flat buffer ([[invariants]] 2). Rows hold byte positions, not text, and JS decodes a row only when asked. Shipping the tree instead of thirteen prebuilt views was 0.64x the bytes and 0.62x the time. [[code:onion/src/wire.rs#parse]] returns bytes and retains nothing, so the engine stays stateless and there is nothing to free.

## Trade-offs

- The reader must match the buffer's version (v5): a shape change means upgrading reader and engine together.
- Consumers build their own views from the tree.
- [[diff]]'s skeleton and [[resolve]]'s answer still return JSON, on cold paths.

## Show me

Native callers stop at `parse`; anything crossing to JavaScript calls `plate`.

```rust
let parsed: Parsed = onion::wire::parse(text, opts); // native callers stop here
let dish: Vec<u8> = onion::wire::plate(&parsed);     // the dish, for anything crossing
```

```ts
const { tree, tokens, diagnostics, toc } = deserialize(parse(text, { diagnostics: true }));
```

The scratch book in [[cst]] plates to 1,072 bytes with `toc` and `diagnostics` on.

## How it works

- **Ship the tree, not projections.** Tokens, CST and diagnostics, not curated planes; each consumer builds the view it needs.
- **One call, several products.** Crossing a typical book cost ~80 µs, which is what forces several products into one call. Statelessness stayed: `parse` returns bytes and retains nothing, so there is nothing to free.
- **Nothing rich crosses.** Flat `Uint32Array` copies plus a few strings. JS never holds a token object; the generated reader is lazy and decodes a row only when asked.
- **Copy is free, encode is the cost.** Measured in Node, `analyze` ran at 1.4–1.5x native; the copy cost nothing, encoding did.
- **Exceptions.** JSON on cold paths: [[diff]]'s skeleton (old camelCase contract) and [[resolve]]'s answer.

## Composes with

Reads `Parsed`: the [[token]]s, the [[cst]], an optional [[lint]] report and [[toc]]. Writes the [[dish]]. The galley [[chunk-cache]] builds a `Parsed` with `Parsed::from_parts` from cached chunks and plates it byte-identically.
