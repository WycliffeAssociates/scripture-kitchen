## The problem

JavaScript apps want the USFM engine, but the engine is Rust. Something has to compile it to WebAssembly and translate at the boundary. Byte positions must become JavaScript string positions, and option objects must be checked. If that layer also grew its own logic, JS and Rust users would get different answers.

## The solution

onion-wasm is a deliberately thin wrapper. Each exported function calls one engine function and converts its inputs and outputs, nothing more. "You could delete this crate and recreate it in an afternoon; that is the point." It is separate from [[onion]] so native Rust users never compile browser code. It still exists beside [[galley]] for apps that want the engine without the proofreader.

## Trade-offs

- The built packages are committed to git, about 370 KB (152 KB gzipped), because consumers install from a git tag, not npm.
- The binary must be byte-identical on every machine, which needs a special build script.
- Input must use LF line endings. CRLF input would put every position one too far per line.

## Show me

Parsing from JS, and a misspelled option failing loudly:

```ts
import { parse } from "onion-wasm";
import { deserialize } from "onion-wasm/schema";
const { tree, tokens, diagnostics, toc } = deserialize(parse(text, { diagnostics: true }));
```

```js
galley.parseText(text, { tco: true });   // throws: parseText: unknown option "tco"; expected diagnostics, toc or utf16
```

## How it works

- **Nothing is implemented here.** Every export tags a library function, plus an offset conversion or a small wire struct where the wall demands it (`README.md`).
- **Byte-identical binaries.** `build.sh` remaps `$CARGO_HOME` and the sysroot and strips the `producers` section, so the same source builds to one sha on macOS/arm64 and Linux arm64/x86_64. That lets CI gate the binary, not just its interface. Release builds run on x86_64 Linux via `wasm-build.sh`.
- **Committed packages.** `pkg-web`/`pkg-bundler` are checked in, one build per target.
- **Options are checked.** Every option bag is a declared interface; an unknown key throws by name rather than reading as `false` (0.1.7).
- **UTF-16 at the wall, LF in.** Offsets out are CodeMirror code units ([[utf16]]).

## Composes with

Depends on [[onion]] and [[mise]]. Linked into [[galley]] under the `wasm` feature, which is how the [[galley-package]] exports every onion door. Ships the [[dish]] reader generated by the [[plate]] codegen.
