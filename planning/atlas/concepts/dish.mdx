## The problem

Sefer needs a whole book's tokens, tree, diagnostics, fixes and chapter/verse index on every keystroke. Materialising those as JS objects and strings per call would cost more than the parse.

## The solution

One buffer: a header, a section directory, and ten sections of fixed-stride integer rows (`tokens`, `nodes`, `childIds`, `diagnostics`, `fixes`, `edits`, `fixText`, `chapters`, `verses`, `members`) ([[invariants]] 2). Rows are from/to offsets into text Sefer already holds, plus enum-numbered kinds; the only text is `fixText`, the bytes a fix would insert. It ships the raw tree rather than views, so consumers build their own. Writer and `reader.ts` are generated from `onion/src/wire/schema.rs` ([[invariants]] 6).

## Trade-offs

- [[code:onion/src/wire/schema.rs#FORMAT_VERSION]] is 5; a reader that does not know the version refuses the dish.
- Every section is listed, even when empty.
- Raw numbers: inspect through the reader, not a debugger.

## Show me

The first 32 bytes of the scratch book's dish (`plate` with `toc` and `diagnostics`). Look at how much is said by plain numbers:

```text
4f 4e 57 52   "ONWR"        magic
05 00 00 00   5             format version
0a 00 00 00   10            section count
00 00 00 00   0             flags (bit 0 = offsets are UTF-16)
ff ff ff ff   NONE          declared \usfm version
7d 00 00 00   125           source length
10 2a 39 c5 03 f0 40 7b     xxh3-64 of the source bytes
```

The ten sections, in wire order:

```text
tokens  nodes  childIds  diagnostics  fixes  edits  fixText  chapters  verses  members
```

## How it works

- **The tree is the product.** `tokens`, `nodes` and `childIds` are the [[cst]] as it lives in Rust.
- **Optional sections are empty, not absent.** The directory always lists all ten, so a reader indexes by slot.
- **`end`, not `len`, on a token.** Every offset field is a plain source offset, so one sorted sweep converts the whole dish to [[utf16]].
- **The source hash** answers "is this the parse of that text" without holding both (`xxh3Text(text) === dish.sourceHash`).
- **The declared `\usfm` version always crosses,** because it gates severities before a single finding can be shown.

## Composes with

Written by [[plate]] from the [[token]]s, [[cst]], [[lint]] report and [[toc]]; generated from its declaration by [[ticket]]'s emitters ([[wire]]). Read by `onion-wasm/reader.ts` in [[onion-wasm]] and [[galley-package]], and so by [[sefer]]. Framed many-at-once by the [[corpus]] envelope.
