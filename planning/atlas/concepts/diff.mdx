## The problem

Reviewing a colleague's copy of a book needs answers per verse ("verse 3 changed"). A line diff cannot give that: one reflowed paragraph is dozens of changed lines.

## The solution

Cut both sides at the [[toc]]'s chapter and verse anchors (no re-scan), align by verse identity, and report each unit as modified, added or deleted; word or character detail is opt-in inside a modified unit. Merge is "take this side" per unit, written out as text or as [[edit]]s. Moves are not detected: a moved verse is a delete plus an add (0.1.8).

## Trade-offs

- JSON, not a binary wire: an accepted exception to [[invariants]] 2 for a cold, modal-open path.
- Word detail grows 66-book JSON from 221 KB to 6.2 MB (17 ms of `JSON.parse`); a binary run wire is parked.
- Word boundaries never cross a footnote edge.

```text
Modified Shared MRK 1:1    -> MRK 1:1
Modified Shared MRK 1:2-3  -> MRK 1:2-3
```

A modified unit's intra-verse runs (`diff.rs` doc), tiling the span:

```text
\v 1 Jesus \add wept\add*.
[\v 1 ]Markup [Jesus]Text [ ]Whitespace [\add ]Markup [wept]Text [\add*]Markup [.]Text
```

## How it works

- **Three layers, one walk.** Identity: a block is the bytes between two [[toc]] anchors, a `Range<u32>` plus a `Copy` address. Alignment: Myers over 12-byte addresses, then coalescing pairs a rebridged or relabeled verse into one decision. Projection: `merge` emits bytes, `to_edits` emits replay splices. PSA against itself: 2.2 ms (commit 09b76e2).
- **Changed units only** unless `unchanged: true` (0.1.8).
- **Runs are asked for by name.** `"none"`, `"words"` (UAX-29) or `"chars"`; an unknown name rejects. The [[cst]] and the `text` [[mask]] are built only when runs are asked for.
- **JSON at the wall.** serde keeps the old editors' camelCase contract (planning item 2026-09-28, binary run wire not scheduled).

## Composes with

Reads the [[toc]] per side, and the [[cst]] and the `text` [[mask]] cut only when runs are asked for. Emits [[edit]]s (`to_edits`, `SpliceEdit`) for replay. Contrast with [[plate]]: diff is the exception to "nothing rich crosses".
