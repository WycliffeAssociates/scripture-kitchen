## The problem

Aligned texts put four to eight attributes on nearly every `\w`, and almost nothing on the per-keystroke path reads them; a word popover and lint do. Typos in them (a missing quote, a stray comma) have to surface, not be absorbed.

## The solution

The scanner keeps `|…` as one `AttrList` token, and nothing splits it until a caller asks: borrowed spans, no allocation, so an attribute-heavy book lexes like a plain one ([[invariants]] 2). A failed pair is [[code:onion/src/attributes.rs#AttrEvent::Malformed|Malformed]] ([[invariants]] 3). usfmtc instead re-reads the whole interior as the default attribute, which repairs the text and hides the slip from [[lint]].

## Trade-offs

- Every reader re-splits; nothing is cached, so a caller reading the same list twice pays twice.
- Not in the per-keystroke dish: a host that wants spans calls [[code:onion/src/attributes.rs#attrs]] per list, on demand.
- Values are verbatim: `x="a\|b"` stays `a\|b`.

## Show me

Each line is one attribute list as written, and what the interpreter reads out of it. Note the bare value and the two malformed cases.

```rust
// `list` is the AttrList token of `\w και|x-strong="G2532" x-lemma="καί"\w*`
let pairs: Vec<AttrEvent> = attrs(src.as_bytes(), &list).collect();
// x-strong=G2532, x-lemma=καί

// |in                     → lemma=in            bare: the row's default attribute
// |lemma=grace            → lemma=grace
// |lemma="grace           → Malformed(UnterminatedQuote)
// |lemma="a", strong="G1" → lemma=a, Malformed(BareJunk @ ,)
// |x="a\|b"               → x=a\|b              no escapes, passed verbatim
```

## How it works

- **A span, not a container.** The [[token]] keeps the list byte-identical, deformed ones included. Splitting it is an interpreter's job (GLOSSARY: a pure function from a slice to a payload), on demand, with no allocation.
- **Malformed, never repaired.** On any pair failure usfmtc re-reads the whole interior as the default value. Here a failed pair is `Malformed`, the finding lint wants.
- **Lazy for hosts too.** Attribute spans are not a [[dish]] section: a section costs every parse for a value only a popover reads. `attrs(text, from, to)` stays the way in, and `reader.ts` carries a `MARKER_ATTRIBUTES` table instead.

## Composes with

Reads one [[token]] span plus the owning row from the [[marker-table]] (`resolve` matches a name against the row). Read by [[lint]]'s attribute rules and the [[exports]]' attribute splat.
