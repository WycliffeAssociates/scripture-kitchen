## The problem

We want to keep the USFM document's offsets, but not pass markup or footnotes through, for proofreading, Sous Chef or a find box. Every hit must still land at its offset in the USFM so the editor can jump to it or edit it. A regex strip loses the offsets after the first cut and has to guess where a note ends.

## The solution

A mask is a named recipe over the [[cst]] that emits the kept text plus the source ranges it came from, so any projected offset maps back exactly ([[invariants]] 1, 2). Recipes: verse text, all text (for [[diff]]), and the structure skeleton. It asks the tree where a note ends rather than re-parsing, and Pad leaves with the marker that owns it. [[find]], [[onion-book]] and the [[mask-map]] wire all read it.

## Trade-offs

- Nothing is inserted: `\add one\add*two` projects as `onetwo`, since a synthesised space has no source offset.
- An offset inside a cut range (mid-footnote) maps to nothing.
- Headings are not verse text.

`playground --mask-trace` on the scratch book in [[cst]]: `verse_text` keeps 45 of 125 bytes in 10 ranges, `structure` keeps 51 in 6.

```text
verse_text:  "\n\n\nJesus wept. Then\nhe Lord   spoke.\n\nBread.\n"
structure:   \id MRK  \mt1  \c 1  \p  \v 1  \v 2-3  \s1  \q1 \v 4
```

## How it works

- **Walks the [[cst]], not the tokens.** "Text is not verse text" is a scope fact: the `why` in a footnote dies because the footnote dies, one skipped subtree instead of a stateful guess (`mask.rs` doc).
- **Public offsets are always source bytes.** Mask space never escapes its maker. A consumer finds something in the projection, calls `to_source`, and files it in document coordinates.
- **Maximal ranges.** Adjacent survivors merge, so a seam between ranges is always a real gap. One `u32` per range, not per byte. ~5.5 ns/token per recipe; the oracle checked 340.9M source bytes over 226 books x 3 filters (commit 9b1e23e).
- **Headings are not verse text** (planning item 2026-09-30). A Titles-and-Sections paragraph's text drops until a `\v` inside it opens a verse; en_ulb puts verses inside `\s5` 208 times in 2CH alone, so removing the subtree would lose them.
- **Character markers drop in `structure`.** Words do not port across languages, which is what makes [[overlay]] possible.

## Composes with
