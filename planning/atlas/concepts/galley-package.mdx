## The problem

A host wants parse, find and Sous in the browser. Two wasm modules would load the shared code twice and let versions drift.

## The solution

One module carries the [[code:galley/src/wasm.rs#Galley]] handle and every stateless onion door. Most doors take either a registered book id (only the id crosses) or raw text. The generated readers ship beside it at the same version ([[invariants]] 6). It installs from the org Nexus npm registry or from a git tag.

## Trade-offs

- The onion doors add 202 KB to the `.wasm`, even for a Sous-only host.
- Not on public npm: a host adds one `.npmrc` scope line for the org Nexus, or pins a git tag.

## Show me

A typical session: load a book, read its outline, publish proofreading findings, search. From `galley/src/wasm.md`:

```js
import { Galley } from "usfm-galley";
import { FindingsSnapshot } from "usfm-galley/sous-reader";
import { Census } from "usfm-galley/toc-reader";

const galley = new Galley();
galley.update("books/MRK.usfm", text);                  // whole book → "MRK"
galley.updateReference("ref/en_ult/GEN.usfm", ult);     // lengths only, no text
const census = Census.open(galley.tocAll());
const snap = FindingsSnapshot.open(galley.publish());
galley.find("books/MRK.usfm", "wept. Then", { caseSensitive: true });

// Places: the cursor's address, and references read and written (the reference crate).
JSON.parse(galley.addressAt("books/MRK.usfm", offset, { utf16: true })); // { kind: "verses", book: "MRK", from, to }
const citations = new Citations({ names: { MAT: ["Mateo", "Mt"] }, intro: ["introducción"] });
JSON.parse(citations.read("Mateo 5:3-7; 6:1"));         // { ok: true, text, addresses, assumed }
JSON.parse(parseReference("MAT 1:20-2:3; MRK 1:1"));     // { ok: true, addresses }
formatReference(addresses); showReference(address, "Mateo", "introducción");
```

## How it works

- **The superset, one module.** A host vendoring one wasm gets both engines. The onion doors cost 202 KB of `.wasm` (744,333 → 946,665 bytes).
- **Two doors per product: by id or by text.** Id doors run off the [[pantry]]'s retained copy. Text doors serve loose text off the same content-addressed chunks.
- **Places cross as Sefer's `Address`**, with its `book` (`BookAddress`). `Citations` holds the book table's English names and codes plus the names the host passes in: no locale's names are linked, so a page loads only the languages it uses, from canon's TypeScript ([[reference]]).
- **Readers are subpaths.** `./toc-reader`, `./find-reader`, `./mask-reader`, `./sous-reader` ship beside the binary so they version with it.
- **Published to the org Nexus on each tag, or installed from the tag.** The repo-root `package.json` is derived by `node package-root.mjs` and CI diffs it.
- **Byte-identical to native.** Three tests pin one set of publication goldens across Rust, wasm and Node.

## Composes with

Built from [[galley]] with [[onion-wasm]] linked in. Reads and writes places with [[reference]]. Answers in the [[dish]], [[census]], [[find-buffer]], [[mask-map]] and [[findings-snapshot]] wires; runs the [[expediter]] over the [[pantry]]. Consumed by hosts such as [[sefer]].
