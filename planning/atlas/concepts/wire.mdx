## The problem

Sefer calls the engine through WebAssembly on every keystroke, and each call covers a whole book. Strings and objects are the cost at that boundary: a string per token allocates in Rust and again in JS, and JSON adds an encode and a parse per call.

## The solution

Offsets over object graphs ([[invariants]] 2). A wire is one flat buffer, mostly fixed-stride rows: positions as from/to integer ranges into text the caller already holds, kinds as enum numbers both sides share, and a string table only where text must travel (book ids, find previews, fix text). Measured in Node, encoding was the cost and the copy was free (13c3d3b). Each format is declared once against [[ticket]]'s vocabulary; the Rust writer and the TS reader are generated and staleness-tested, and a reader refuses a buffer of the wrong version ([[invariants]] 6).

## Trade-offs

- Versioned: a shape change bumps the version, and every consumer takes the new reader.
- Cursor reads, not objects: harder to eyeball than JSON.
- Two formats are still partly read by hand: the [[corpus]] envelope and sous-core's snapshot.

## How it works

- **No mirrors.** Before 0.1.0, `onion-wasm.ts` held 109 hand-mirrored constants (commit b781bb9). Generating both ends from one declaration took that to zero.
- **A consumer never learns a layout.** Each reader checks magic, version and strides at `open` and throws naming the mismatch, so a reader a version behind fails loudly instead of misreading a field (`architecture.md`).
- **Little-endian by construction.** A field declares its name, width, whether it is a source offset ([[code:ticket/src/schema.rs#Space::Offset]], converted under `utf16`), and the expression that reaches it. Nothing casts a Rust struct.
- **Encode is the cost, copy is free.** Measured in Node before the formats were fixed: analyze ran at 1.4–1.5x native (commit 13c3d3b). Crossing a typical book cost ~80 µs, which is why one call returns several products ([[plate]]).
- **Checked in at both ends.** `codegen_output_matches_input` fails the build when either end is stale.
- **Debt**, named in `architecture.md`: the [[corpus]] envelope and sous-core's reader are still partly typed by hand.

## Composes with

The vocabulary and emitters are [[ticket]]'s. Each format's envelope stays with the format. [[plate]] is why the wires are binary at all.
