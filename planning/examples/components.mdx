Every component an item can use, written against this template's own files. It is a
reference for syntax, not an item: it lives outside `items/`, so the site does not build it,
and its paths only resolve in the template repo itself. To see it rendered there, copy it
into `items/` and run `pnpm dev`.

Components whose body is code or indented text take it as a fenced block inside them: MDX
strips up to two leading spaces from every line of a `{`…`}` attribute.
