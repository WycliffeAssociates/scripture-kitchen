`SourceCopy` (wire code 3, U1) publishes runs of target words that appear
exactly in the source verse, and refuses to call them untranslated.
`LengthConfig::source_copy` ships off: against a same-family source the tier
fires about two rows per verse (evidence.md, U1).

Detection proper (names excused, legitimately shared words excused) was never
built and was not promised. See
[rules/source-copy-residue.md](sous-chef/rules/source-copy-residue.md).
