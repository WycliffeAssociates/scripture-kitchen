# Conventions

- Comments: lean, present-tense, only for constraints the code cannot show.
  No history narratives, plan references, or dates.
- Module docs lead with input→output example blocks; prose only for what an
  example cannot say.
- `debug/` (gitignored) holds eyeball dumps regenerated by playground modes
  (`--mask-trace`, `--vref`, `--format-trace`). Refresh them when the bytes
  they show change.
- Decision ledger: per-pass choices go in `planning/choices.md`; invariants in
  the spec they belong to; sous-chef findings in `sous-chef/evidence.md`.
- Measure before optimizing a hot pass: scalar, SIMD, and memchr ceilings
  first, so every pass is a measured subtraction.
