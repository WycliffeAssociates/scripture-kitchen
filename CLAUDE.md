# usfm_onion_2

Rust USFM engine. Design authority lives in `planning/` — sketches per
feature, `planning/choices.md` (the decision ledger: banked entries are
givens), `planning/settled-facts.md`, `GLOSSARY.md`.

## Tests: inner loop vs pass-end gate

- In the loop, run TARGETED tests for the feature you're on:
  `cargo test --lib format`, `cargo test --test format_corpus`, etc.
- Exhaustive oracles that take minutes are `#[ignore]`d (the ignore
  reason says so). They are NOT optional: the finish-line check for any
  pass is the full suite INCLUDING them —

      cargo test -- --include-ignored

  A pass is not done until that is green, plus `cargo clippy
  --all-targets` clean.

## Conventions

- Do not commit; leave the tree for Will's review (he commits on
  explicit ok).
- Every pass appends a self-report to `planning/choices.md` in the
  ledger's style: each choice made where the spec was silent, with the
  concrete scenario that forced it.
- Comments: lean, present-tense, only for constraints the code can't
  show. Module docs lead with input→output example blocks.
- debug/ holds eyeball dumps regenerated by playground modes
  (`--mask-trace`, `--vref`, `--format-trace`); refresh them when the
  bytes they show change.
